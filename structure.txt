IRC Project Structure — Task Distribution
📌 Project Objective

The IRC project consists of developing an IRC server in C++ capable of:

handling multiple clients simultaneously,
allowing communication between users,
managing channels,
implementing the main IRC protocol commands.

The server must use non-blocking sockets and poll() to manage multiple connections without threads or forks.

🧱 General Project Architecture

The project will be divided into several modules to clearly separate responsibilities.

🌿 Git Organization
Each member will work on a separate branch:

Merges will be done progressively after validating features.
